Hi everyone — this is K-Nexus, our marketplace for agentic AI. Everything I'm about to show you lives in one place: assess where a client actually stands, forge an agent for the gap, and pull from a live catalogue once it's built. I'll move fast — five minutes, real screens, no slides.

0:20

Assessments

SCREEN /assessments → Procure-to-Pay Automation → SMB Managed Services

We start with Assessments. These aren't forms — every field arrives pre-filled with a benchmark, and the client's job is just to correct it live in the room.

Here's Procure-to-Pay: you tell it their ERP landscape, it guesses which parts of the process are already automated, they correct it, and it scores where they actually stand — then hands the gap straight to the agent that closes it.

Same engine, a completely different domain — this one profiles an SMB by size and IT setup and recommends which managed-services bundle actually fits their problem, not a product list. We've also got two maturity benchmarks running the same pattern — a Telecom AI & Agentic Maturity index and an Agentic Readiness Index.

1:30

Agent Forge

SCREEN /forge

Once an assessment finds a gap, Forge is where you close it. No code — you configure tools, guardrails and behaviour through a guided wizard, and out comes a working agent. This is the build side of the marketplace.

2:05

The knowledge graph

SCREEN /tmt-ontology → Billing Assistant → CFO Intelligence

Underneath all of this sits the knowledge graph — the TMT Ontology. This is the entity model for the whole sector: infrastructure, AI ops, cloud, customer, network, every relationship between them, in one graph.

And it's not just a diagram. Two live agents already run on top of it — this is a telecom billing agent, live right now, and this is a CFO intelligence agent. Both pulling from the same ontology you're looking at. That's the point: build the graph once, and every agent on top of it inherits the same understanding of the sector.

3:20

Capability map

SCREEN /capability-map

One more piece worth a glance — the Capability Map. Same idea as the ontology, built for a specific conversation: hover any node and it traces everything connected to it, live. One map for vendor-agnostic architecture decisions, one mapping personas to their problems across a day, a month and a year.

3:45

The catalogue — Datacenter & AI Ops

SCREEN /agents/datacenter-lifecycle-intelligence → /agents/aiops-sentry

And that's the loop — assess, forge, connect to the graph — landing in one catalogue of live agents. Two to leave you with.

Datacenter Lifecycle Intelligence manages the full asset lifecycle — provisioning to decommission — with AI-driven capacity planning and refresh scheduling. AIOps Sentry watches network and IT operations in real time and predicts incidents before they hit service. Both live in the same catalogue as everything else you just saw.
